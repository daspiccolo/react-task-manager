# React Task Manager (Portfolio)

A simple Task Manager app built with React + Vite + Tailwind, featuring:
- Authentication (login/register)
- Tasks CRUD (create, list, toggle done, delete)
- Filter + search
- Redux Toolkit
- JSON Server as a mock API

## Tech stack
- React (Vite)
- TailwindCSS
- Redux Toolkit
- Axios
- JSON Server
